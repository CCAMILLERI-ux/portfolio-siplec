# portfolio-siplec

Portfolio de candidature de Caroline Camilleri – Responsable projets marketing digital.

Concept exploratoire réalisé dans le cadre d'une candidature, sans lien avec SIPLEC ni E.Leclerc. Données fictives.

## Pages

- `index.html` : accueil (présentation, deux cas, correspondance avec les axes du poste, méthode, pilotage, usage de l'IA)
- `cas-energie.html` : cas 1, page publique, FAQ, formulaire guidé en trois étapes, webinaire, tests, RGAA, SEO/GEO, lancement
- `cas-non-alimentaire.html` : cas 2, showroom professionnel (recherche, filtres, fiches, comparaison, sélection), kit d'animation
- `design-system.html` : documentation de la bibliothèque de composants de démonstration

Référence visuelle : `SIPLEC-PORTFOLIO-DESIGN-SYSTEM.md` (bibliothèque de démonstration, pas le design system officiel de SIPLEC).

## Technique

HTML, CSS et JavaScript natifs, sans build. Liens relatifs, compatibles avec `https://ccamilleri-ux.github.io/portfolio-siplec/`.
Aucun backend, aucun envoi de formulaire, aucun stockage, aucun traceur. Seule ressource externe : Google Fonts (Montserrat, Poppins).
